## Featured work

### Echo — private local intelligence for macOS

Echo is a private local-first macOS product for cross-application dictation and evidence-grounded meeting intelligence.

- Swift, SwiftUI, AppKit, Core ML, and MLX Swift
- Local speech and language-model routes
- Deterministic vocabulary and spoken-command processing
- Evidence validation before structured meeting output
- Safe active-application delivery with clipboard fallback

The product source, model weights, credentials, private transcripts, and unreleased features remain private. The public repository is a reviewed engineering case study.

**Explore:** [case study](https://github.com/EmilianoOnTheRunn/echo-local-intelligence) · [showcase](https://echo-local-intelligence.pages.dev) · [full Echo film](assets/echo-benchmark-film.mp4)

## How I work

- Start with the user, the decision, and the cost of failure.
- Separate model behavior from product safeguards and delivery behavior.
- Make permissions, artifacts, review points, and “done” explicit.
- Keep the protocol and limitations beside every benchmark.
- Prefer local processing when privacy, latency, or reliability benefit from it.
- Ship the whole path: tests, packaging, permissions, recovery, and documentation.
